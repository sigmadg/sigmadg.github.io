Las imágenes de cómo se ve cada flujo se cargan desde la carpeta Imagenes (en la raíz del proyecto).

En Imagenes están las capturas: Selección_565.png, Selección_566.png, etc.
El portafolio asigna cada imagen a un proyecto en orden (1.º → Aeroespacial, 2.º → Fintech, …).

Para que se vean, sirve la carpeta raíz del proyecto (donde están web/ e Imagenes/), por ejemplo:
  npx serve .
y abre http://localhost:XXXX/web/
